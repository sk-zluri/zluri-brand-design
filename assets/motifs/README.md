# Motifs

SVG motifs exported directly from the Figma file "Zluri Marketing Brand Design System". Gallery: `preview/motifs.html`. Usage rules and CSS recipes: `guidelines/02-visual-language.md`.

| File | Motif | Notes |
| --- | --- | --- |
| `z-overlay-shape-large.svg` | Z colour overlay, square | The wordmark *z* enlarged and rotated; `mix-blend-mode: multiply` over a greyscale photo. Change `fill` to a brand colour. |
| `z-overlay-shape.svg` | Z colour overlay, 1200x250 band | For photo header bands. |
| `wordmark-crop-solid.svg` | Cropped wordmark, solid | Place flush right at full canvas height; recolour tone-on-tone or with a gradient. |
| `wordmark-crop-outline.svg` | Cropped wordmark, outline | For light backgrounds. |
| `corner-arc-lines.svg` | Three rounded-corner hairlines | Top-right of banners. |
| `concentric-arc-bands.svg` | Soft concentric bands | Tone-on-tone; sweep from a bottom corner. |
| `orbit-ellipses.svg` | Orbit ellipses | 30-40% opacity on dark covers. |
| `z-maze-pattern.svg` | Z-maze line pattern | Tone-on-tone on Deep Blue (people posts). |
| `quote-mark.svg` | Gradient quote mark | Academy quote slides; rotate 180 degrees for the closing mark. |
| `chain-link.svg` | Gradient link | Partnership and testimonial video. |
| `sparkle-star.svg` | Gradient star | Academy title-card accent. |

Colours inside these files are the ones the designers used in the source frame; recolour within the palette as the context requires.

# Logos

Zluri is **an Infotech company**. The default logo for every design is the **Zluri × Infotech lockup** in `primary/`.
Files are named by the **background they sit on**.

| Folder | Files | Use |
| --- | --- | --- |
| `primary/` **(default)** | `zluri-infotech-on-light.(svg\|png)`, `zluri-infotech-on-dark.(svg\|png)` | Wordmark + "AN INFOTECH COMPANY". Dark wordmark for light backgrounds; white wordmark for dark, coloured, photo and gradient backgrounds. Use whenever the brief doesn't name a logo. Min. width 110px / 25 mm. |
| `primary/original-padded/` | `zluri-infotech-dark.*`, `zluri-infotech-white.*` | The files exactly as supplied (635×360 artboard with padding). Reference only — use the cropped files above. |
| `wordmark-only/` | `zluri-wordmark-on-light.(svg\|png)`, `zluri-wordmark-on-dark.(svg\|png)` | Pre-acquisition wordmark without the endorsement. **Only when the user asks for it.** |
| `monochrome/` | `zluri-mono-on-light.(svg\|png)`, `zluri-mono-on-dark.(svg\|png)` | One-colour wordmark. **Only when the user asks for one-colour / monochrome.** |
| `tagline-lockup/` | `zluri-tagline-on-light.(svg\|png)`, `zluri-tagline-on-dark.(svg\|png)` | 2025 wordmark + "Next-Gen Identity Governance & Administration". **Only when the user asks for it.** |
| `mark/` | `zluri-eye-mark.(svg\|png)` | The concentric eye mark alone: favicon, avatar, bullet glyph, diagram hub — where the lockup can't reach 110px. |

Source of `primary/`: `D:\Zluri Files\Brand\Zluri ITRG Final Logos` (supplied Nov 2026). The SVGs here are the supplied artwork with the viewBox cropped to the logo (`105 72 426 230`); PNGs are rendered from them at 4×.

Rules (sizes, clear space, co-branding, don'ts): `guidelines/01-brand-foundations.md`.

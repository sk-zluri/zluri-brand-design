# Zluri Brand Design System

This repository is a design system for producing Zluri-branded work. Before designing anything, read `AGENTS.md` and follow its read order and routing table.

Key rules: look at reference images in `references/` before designing; start from `templates/`; use only `tokens.css` values; ask the user before sourcing any stock photo (`guidelines/10-photography-and-stock.md`); run `guidelines/12-anti-slop-checklist.md` before presenting.
